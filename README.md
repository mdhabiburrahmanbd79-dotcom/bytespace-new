# ByteSpace New

React + Vite implementation of the ByteSpace landing page assessment.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Git workflow
Create a feature branch, commit the project, push it to GitHub, then open a Pull Request into `main`.

## Deploy
Import the GitHub repository into Vercel. Vercel will detect Vite automatically.
